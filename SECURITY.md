# Relatar uma vulnerabilidade

Envie o relato pelo [canal privado de segurança do MyCity no GitHub](https://github.com/Duck1201/MyCity/security/advisories). Na área **Security and quality**, escolha **Report a vulnerability**. A equipe responsável acompanha o relato pelo próprio GitHub.

Inclua a versão ou o commit afetado, o comportamento observado, o impacto e as evidências sanitizadas. Mantenha os detalhes no relato privado e remova credenciais, dados pessoais e anexos de usuários. Use o canal público de issues para problemas comuns.
