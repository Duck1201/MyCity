## Fidelidade às fontes

As transcrições mantêm o conteúdo das fontes; quebras de linha e tabelas foram adaptadas para Markdown e cabeçalhos/rodapés repetitivos foram removidos. Os retratos ilustrativos das personas não foram incluídos na extração textual.

As referências não foram conciliadas entre si. Por exemplo, a lista geral de UC01 nos casos estendidos cita RF01, RNF01 e RNF02, enquanto o detalhamento também cita RF12 e RNF06. Essas diferenças foram preservadas para decisão futura do projeto.

## Organização atual

Os cinco documentos acima são fontes históricas, movidas sem alteração de conteúdo. Este índice teve apenas caminhos e orientação de localização atualizados. A especificação conciliada está no [índice da documentação](../readme.md). As decisões do MVP não alteram retroativamente as fontes.
